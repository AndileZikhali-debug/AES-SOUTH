AES SOUTH MULTI-PAGE WEBSITE

Pages: index.html (home), about.html, mission.html, youth.html, framework.html, register.html, contact.html
Shared styling: styles.css, pages.css. Shared interactions: script.js.
Assets folder includes an editable vector placeholder emblem (assets/aes-mark.svg). Replace it with approved official branding if available.
The enquiry forms use mailto and do not save submissions to a database. This is a static front-end package. For actual server-side registration, connect to a backend/API and secure database.
Keep AES_SOUTH_Constitution.pdf in this folder if the constitution link should work.
Open index.html to preview locally, or upload the folder to a static hosting provider.
